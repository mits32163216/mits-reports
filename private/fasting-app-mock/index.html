ファスティング記録アプリ（スマホ版）モック

2026-10-20 時点の記録表の数字をそのまま入れた見本です。今の記録表（https://reports.7years.life/private/fasting-kiroku/）は1日1列の表ですが、スマホでは「今日の1日」を縦に読む形に組み替えます。動きは付いていない見本です。

1日の動き（Mits様の入力のしかたから組んだ順番）

朝
  1. RENPHO に乗る
  2. 体重・体脂肪・前日の歩数と消費が自動で入る（今の毎朝の自動入力をそのまま使う）
  3. 通知「今日の摂取可は 970kcal・目標との差 +0.2kg」
昼
  1. 写真を撮る＋ひとこと（例「唐揚げ　おかずだけ」）
  2. AI が内訳つきで見積もる（揚げ油・たれ・部位の基準どおり）
  3. ご飯の有無・量を1回押して直し、「記録する」
夕方〜夜
  1. 今日の画面で「残り」を見る
  2. 予定の卵・納豆・泡盛は丸を押すだけ
  3. 超えていたら、指導のカードが「夜はカチュー湯だけ」と出す
翌朝
  1. 2日の合計と体重の動きが並んで出る
  2. 目標との乖離・原因（どの食事か）・対策が1行ずつ出る
  3. 目標は動かさない

考え方

記録表から引き継ぐもの

  • 消費＝基礎代謝＋活動代謝＋食事による消費の3つに分けた式と、脂肪から燃える量の1日の上限
  • 1日の残りと2日の合計の残り、達成は青・超過は赤
  • 目標体重は始めの計画の式のまま動かさない
  • チェックを端末どうしで揃える仕組み（今の Worker fasting-sync）と、毎朝の自動入力

スマホで新しく足すもの

  • 写真＋ひとことから AI が内訳つきで見積もる（今はこのセッションに送っていただいている部分）
  • お店の献立を覚えておく（ちょーでー弁当など）。2回目からは押すだけ
  • ヒスタミンで避ける食べ物（魚・大豆・発酵食・作り置き）が入ったら、記録する前に知らせる
  • 超過した日は、指導のカードが夜と翌日のふるまいを出す

作るときに当たること

  • 写真の見積もりをアプリの中で行うには、Claude の API を呼ぶ中継（Worker）が要る。API の利用料がかかる
  • ファスティング計画webアプリ（https://reports.7years.life/private/fasting-keikaku/）が別の持ち場で公開済み。計画を組む側はそちらにあるので、こちらは「毎日つける・振り返る」に絞ると重ならない
  • Mei さんの記録表も同じひな形なので、1つのアプリで人を切り替えられる形にすると2本作らずに済む

今の記録表との違い

  • 表は1日1列で全期間を横に見る。スマホは「今日」を縦に読み、全期間は振り返りの図に回す
  • 見る順番を「残り → 2日の合計 → たんぱく質 → 体重」に固定した（Mits様が実際に見ている順）
