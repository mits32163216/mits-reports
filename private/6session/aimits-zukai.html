8. Dify の名前を付け替える（案 ── まだ反映していません）

Mits様のご指定の形は「頭の括弧（中身で何をしているか）＋ 番号 ＋ FAST／NORMAL／DEEP」。 括弧の中身は今の中身に合わせて付け直す（2026-09-11 Mits様）。

今の名前付け替え後
1AI-MITS(R)AI-MITS(ナレッジ無し) 14d6df13 FAST-APP
2AI-MITS(M) 西田メソッドAI-MITS(RAG) 43d47f25 NORMAL-APP
3AI-MITS (C)AI-MITS (Corpus2Skill) 1a8d8b9c DEEP-APP
4AI-MITS v2AI-MITS v2 e472bc1f NORMAL-WEB
  • 区切りは半角スペース1つ
  • 括弧の中身は「今そのアプリが何をしているか」に合わせる（2026-09-11 Mits様）。 頭文字1文字（(M) (R) (C)）では中身が分からないため、開いた言葉に置き換える
  • AI-MITS (Corpus2Skill) は、今の名前どおり AI-MITS と ( の間に半角スペースを1つ残す。 他の2つは今の名前どおりスペース無し
  • アイコン（🧭 💬）は Dify が名前とは別に持っているので、名前の欄だけを書き換える
  • 末尾で繋ぎ先を分ける（2026-09-11 Mits様）── 運転台アプリ側の3つは -APP、WEB（お試し版）が向いている v2 は -WEB

括弧の中身が入れ替わった経緯（2026-09-11 のやり取り）

  • 今の名前の (R) は RAG、(C) は Corpus2Skill の頭文字
  • ところが (R) が付いている 14d6df13 は、いま RAG をしていない（箱3個・ナレッジ検索の箱が無い）。 実際に RAG をしているのは 43d47f25 のほう（箱4個・dataset 11963425 を引いている）
  • そこで (RAG) は 43d47f25 へ、14d6df13 は (ナレッジ無し) へと付け直した。 名前を見れば中身が分かる状態にするのが目的

なぜ「ナレッジ無し」を FAST だけに付けるか

箱の数ナレッジ検索の箱{{#context#}}材料は入るか
FAST（14d6df13）3個無無入らない
NORMAL（43d47f25）4個有（dataset 11963425）有入る
DEEP（1a8d8b9c）13個無（Notion API を直に叩く）無（USER 欄で渡す）入る

DEEP にもナレッジ検索の箱は無いが、あちらは Notion を直に叩いて台帳を全部たどる作り。材料が入らないのは FAST だけ。

これは不具合ではなく、決めてそうしたもの。
