I. 守る決まり（画面と報告に効くもの）

  • 色は文字だけ。塗らない・囲まない
  • 割合の決め打ちを、お客様に見える場所に書かない。比べる相手は自分の平均だけ
  • 測れないものは「測れません」と書く。測れた 0 件と、測れないものを分ける（実装は pf() が == null だけを「測れません」にし、測れた 0 は 0.00% と出す）。項目が無い経路のグラフは描かない（0% の線は嘘になる）
  • 「その経路の印が付いた押下が0件」と「誰も来ていない」は別。実測：Worker の押下 66件のうち spro 37／utage 14／印が落ちた不明 11（16.7%）／magmag 2／utm_source でない値 2。経路別の比較は下限寄りになる

  • 特定のサービス名を画面にも並び順にも焼かない
  • 送信数と読者数を同じ線・同じ列に混ぜない（横軸が違う）
  • のべ数は割り算に使わない（100%を超える）
  • 送った直後の数字で良し悪しを決めない。1配信につき最後に測った1回で揃える
  • 運転台に測定の仕組みの読み口を焼かない（買った人はその仕組みを持たない）
  • 生データは残し、除外前と除外後の両方を持つ。除外条件はアプリに焼き付けない
