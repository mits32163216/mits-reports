6セッション共通 用語一覧（2026-09-16 版）

2. 「札」の分解（Mits様確定・2026-09-16 16:1x〜16:3x）

「札」は英語の何かの訳ではなく、AI が「1つずつ付いている物」を言い表そうとして作った造語だった。同じ語で7つの違うものを指していた。

Mits様原文：「札という言い方もピンとこない　この文脈で英語の単語は何を札と訳している」／「同じ単語で違う意味は将来あやまちの元、このセッションでも修正する」

#使う語実体例
①端末の番号計測系 aimits_uid（base36 16文字）・認証系 anon_uid（UUID v4）「端末の番号が2体系ある」
②相談の利用者名Dify が会話を分ける名前。try-… / untendai-…・localStorage の aimits_try_user「Dify に渡す 相談の利用者名」
③追跡の印リンクに付ける計測の印の一式（utm_source / utm_campaign / utm_content）動詞は「経路の印を付ける」「印つきで来た」「印なしで来た」「印が落ちた」
④campaign の値号を見分ける名前（utm_campaign の値・例 20260914_imadoko）「この号の campaign の値は 20260914_imadoko」
⑤最後に付いていた印直近に付いていた印（saved_utm / aimits_utm に残る前回の値）「最後に付いていた印を見る」
⑥申し送り定時報告の申し送り1行（yobidashi.md の表の1行）「申し送りに置く」
⑦判定待ち運転台の画面の中の小さい表示（8件・HTML コメントと // の中だけ・顧客の画面には出ない）候補：目印／見本の表示／状態の表示（司令塔の推しは 目印）

🛑 一括置換をかけない

同じファイルの中に①と③が並んでいる。実例（司令塔の全体設計図・2026-09-16）：


L223  端末の札（uid）                      ← ①
L424  Dify の名札の頭（try-／untendai-）   ← ②
L247  札の付け方は 2026-09-08 確定          ← ③

機械で一度に置き換えると、①が③の言葉になって意味が壊れる。行ごとに①〜⑦を見分けてから当てる。

3. 似ていて別物（取り違えると数字が狂う）

語語何が違うか
経過ラベル（事後97h・24h）追跡の印（utm）ラベルは測ったタイミングの見出し。印はどの経路から来たか。台帳では別の列に分かれている（運転台マーケの指摘・2026-09-16）
UTAGE の登録（29件）reg_submit（1件）登録は成立した人の数。reg_submit はお試し版の窓で「確認のメールを送る」を押した回。別のものを数えている（AI-Mits-チューニングの指摘・2026-09-16）
語の出た回数（`grep -o <語> \grep -c ''`）語の出た行の数（grep -c <語>）1行に2回出る行があると差が出る。人に渡すときは物差しの名前を添える
wc -lgrep -c ''wc -l は改行の数を数えるので、最終行が改行で終わっていないファイルでは1少なく出る。`tail -c 1 <file> \od -c` で末尾を見てから渡す

4. 直す範囲・直さない範囲

直す：6セッションの仕組みに関わるもの（司令塔のフォルダ・各持ち場の手順書・全体設計図・計測の台帳・社内レポートの正本・共有 memory）。

直さない：

  • 記録の中の引用。決定の記録の「札」22件は、ほぼ全部が Mits様の原文引用か「呼び出し札 → 申し送り」という置き換えの記録だった。書き換えると「何を何に変えたか」が読めなくなる。Mits様の原文は一字も変えない
  • 済んだ回の記録（asa_tenko.md）。当時そう呼んでいたという証拠
  • 控えファイル（_控え_ _mae _前 を名前に持つもの・AI作業ゴミ箱の中）
  • 6セッションと関係のない資料。うちなーぐち辞書の単語25件・配信の生データ・過去のメルマガ原稿・和佐式の資料・法人登記の資料など。ここの「札」は値札・名札・お札といった普通の日本語で、この表とは無関係

範囲を広げて数えると392件出るが、当てるべきはその一部（2026-09-16 実測・経営プロジェクト配下＋共有 memory の 2,541本を走査）。数えることと、当てることは別の作業。数えたあとで1件ずつ判定する。
