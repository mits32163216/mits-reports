1. これは何をするものか

自分の歌を録音して読み込ませると、声を数値にして、前回からどう変わったかを出します。上手い下手を採点する道具ではなく、練習でやったことが効いたかどうかを確かめる道具です。

やること

歌う → 録音を読み込ませる → 数字が出る → 前回と比べる → 次に何をやるか決める。この輪を回します。

声はどこにも送られません

解析はすべて自分のブラウザの中で終わります。録音そのものがネットに出ることはありません。保存されるのは解析後の数値と、自分で書いたメモだけです。

2. はじめての設定（1回だけ）

記録は「個人ID」ごとに完全に分かれています。他の人からは見えません。

  1. 誰かからURLをもらった場合：そのURLを開くだけで設定は終わりです。何もしなくて構いません。
  2. 自分で始める場合：設定ページを開いて「自分のIDを作って始める」を押します。
  3. URLを控えておく：設定ページの「自分のURLをコピー」を押して、メールやメモ帳に貼って保存します。
  4. 別の端末でも見たいとき：控えたURLをその端末で1回開けば、以後は同じ記録が出ます。

URLは必ず控えてください

IDを控えないまま端末のデータを消すと、それまでの記録に辿り着けなくなります。復旧する手段はありません。

3. 録音のしかた（ここが一番大事）

数字は録音の条件に強く引きずられます。毎回同じ条件で録ることが、正しく比べるための前提です。条件が変わると、歌が変わっていなくても数字が動いてしまいます。

この3つを必ず守る

  • ガイドボーカルは切る — お手本の歌声が混ざると、それを自分の声として測ってしまいます。
  • 伴奏（BGM）の音量は小さめ — 伴奏が大きいと声の細かい部分が埋もれます。
  • イヤホンのマイクをスマホに直挿しして録る — カラオケ店のマイクや部屋の反響を通すと、声そのものではなく部屋を測ることになります。

具体的な手順

  1. マイク付きイヤホンをスマホに挿す
  2. スマホの録音アプリ（ボイスメモ等）を録音状態にする
  3. カラオケ側でガイドボーカルを切り、伴奏の音量を下げる
  4. 歌う（曲の頭から終わりまで通しで録る）
  5. 録音を止めて、ファイルを保存する

2回目以降で気をつけること

マイクの種類・伴奏の音量・部屋を変えると、前回と比べられなくなります。条件を変えたときは、そのことをメモに残してください。数字が動いた理由が歌なのか条件なのか、後から分からなくなるのを防げます。

4. 毎回の流れ

  1. 録音する（上の条件で）
  2. 解析 を開いて、録音ファイルを選ぶ。曲名を入れて解析を押す。5分の曲でおよそ50秒かかります（機種によって前後します）。
  3. 実測 で数字の全体を見る。課題 でいまの立ち位置を見る。
  4. 日記 に、その日やったこと・意識したことを書く。
  5. 検証 で、やったことと数字の変化がつながったかを確かめる。
  6. 次にやることを 計画 と 基礎 から選ぶ。

メモを書くのを飛ばさない

数字だけ貯めても、なぜ動いたのかが分かりません。「今回はここを意識した」を一行書いておくだけで、後から効果を確かめられるようになります。

5. 数字の読み方

出てくる数字は2種類あります。この2つを混ぜて見ると判断を間違えます。

種類意味見方
🟢 改善指標 上がったら歌が上手くなったと言い切れる数字 これを追いかける。前回より良くなっていれば、その練習は効いた。
🔵 状態指標 いまの声がどういう状態かを説明する数字 上げにいかない。今の立ち位置を知るためのもので、良し悪しではない。

偏差値について

50 が平均です。実際に歌っている人たちの録音を集めて分布を作り、その中での位置を出しています。数字が低くても悪いという意味ではありません。どこが自分の伸びしろかを見るためのものです。

そして、比べる相手は他人ではなく前回の自分です。偏差値そのものより、前回からどちらへ動いたかを見てください。

1回の結果で判断しない

その日の喉の調子、録音条件、曲を覚えているかどうかで数字は動きます。同じ曲を何回か録って、傾向で見てください。1回だけ良かった／悪かったは、まだ何も意味しません。

6. つまずいたとき

解析が終わらない／固まる

曲が長いと数分かかります。画面を閉じずに待ってください。5分以上戻らないときは、ページを再読み込みしてもう一度試してください。

別の端末で開いたら記録が空だった

その端末にまだ個人IDが入っていません。設定ページで「自分のURL」を貼って切り替えてください。

数字が急に悪くなった

まず録音条件を疑ってください。マイク・伴奏の音量・部屋のどれかが前回と違うと、歌が同じでも数字は動きます。条件が同じなら、その日の調子か、覚えていない曲を歌ったかのどちらかであることが多いです。

はじめて歌う曲を混ぜてよいか

録っても構いませんが、歌詞も曲調も覚えていない段階の録音を平均に入れると全体が歪みます。実測ページで、その曲を集計から外す切り替えができます。

画面の隅に「同期できず」が出たまま消えない

記録をすべて消した直後に出ます。クラウド側は、端末のデータが不意に飛んだときに巻き込まれないよう、空の状態では上書きしないようになっているためです。全部消したのが意図どおりなら、解析を1回すれば元に戻ります。心当たりが無いのに出ている場合は、まだ記録が残っている可能性があるので、この端末のデータを消さずに設定ページで個人IDを確認してください。

記録を他の人に見せたい

自分のURLの末尾に &view=guest を付けて渡すと、相手は見るだけで書き換えできない状態になります。
