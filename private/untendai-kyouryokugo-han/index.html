4. 協力体制で変わった土台 ── 版ではなく仕組みの変化

いつ何が変わったか
10-15森田さんが Discord に参加。サーバー名は「経営の運転台 開発」。連絡は Discord が中心で、いまのチャンネルは4つ（はじめに・ディスカッション・各自の版・本流の更新）。
10-15共同開発の決まりを整えた。始め方を書いた案内、取り込み依頼と不具合・要望のひな形、取り込み依頼のたびに自動で試験を走らせる仕組み。手元の AI の作業記録をコードから外した。
10-16GitHub の協力が始まった。森田さんを招待し、森田さんは本流から分けた自分の版を持った。
同じ日に、本流を GitHub の組織 untendai の untendai/untendai に移した。非公開のまま。本流に書き込めるのは西田だけという規則を入れた。更新を配る中継も、新しい住所に切り替えた。
10-16Windows の試験の直し。Windows でだけ落ちていた試験4件を直し、家のフォルダが無い Windows でも動くようにした（Windows 上で 315 件通過・失敗 0）。GitHub 上で落ちていた試験1件も直した。ほとんど使っていなかった GitHub 上の Windows 組み立てはやめた。
10-16〜17森田さんが、4カテゴリーの新しい画面を自分の版で作った（ホームの4つの区分・左のメニュー・AI-Mits の欄・試作の画面・スマホ幅）。設計の書類とスクリーンショットは、西田の設計リファレンスから起こした。
10-19森田さんの変更を取り込む道ができた。「変更点一覧」の画面で取り込みたい行にチェックを入れ、「チェックしたものを取り込む」を押すと依頼が受け付けられ、取り込み担当が西田統合版へ入れる。最初の依頼は18件で、v1.77.0 になった。
10-19版の呼び方を決め直した。開発版 → 西田統合版 → 確認版 → 正式版。新しく「確認版」の段を足した。段ごとの受け持ちも決めた（上の「2」）。版を分けたら、左上の（〜版）とアイコンの色を一緒に決める決まりにした。

「1」「2」の番号と「3」の最後の行は、版を作るたびに道具（untendai-seiri の tools/han_page_koushin.sh）が実物から取り直す：各 .app の版・更新を配る中継が返す正式版（latest.json）と確認版（kakunin.json）の番号・GitHub untendai/untendai のリリース一覧と版の印・CHANGELOG.md・WEB版の作業場の記録。取り直した時刻は冒頭に書く。「3」の 1.77.6 までの行と「4」は 2026-10-19 17:40 の実測。呼び方と受け持ちの正本は、経営の運転台の案件の決まりの冒頭と決定台帳（2026-10-28 20:5x・21:0x・20:1x）。古い全体像は別ページ「運転台 開発の流れと現状」にある。
